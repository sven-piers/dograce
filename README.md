# DogRace

Site de la marque fictive DogRace (croquettes haute énergie pour lévrier de course), projet de groupe du cours de Growth hacking, M2 IMT&E, Université Paris 1 Panthéon-Sorbonne.

Tout le site tient dans `index.html` (images et vidéo intégrées). Chaque push sur `main` est publié automatiquement sur Netlify.

Groupe : Burcu Sisman, Melvin Perrot, Zarina Rodriguez Ricci, Sven Piers.
